음식 사진 한 장으로
손그림 친구들이 노는 푸드 포스터 만들기

음식 사진이 이야기가 있는 그림이 돼요.
가게 홍보나 인스타에 올리기 좋아요.

1이런 사진이 좋아요

  • 음식이 크게 나온 사진캐릭터들이 음식 위에서 놀아야 해서, 음식이 화면을 많이 차지할수록 재미있게 나와요.
  • 질감이 살아 있는 사진바삭한 겉면, 소스, 김, 층층이 쌓인 모양이 보이면 캐릭터가 그걸 타고 놀아요.
  • 글자가 없는 사진원래 사진에 글씨가 있으면 손글씨와 겹쳐서 지저분해져요.
제가 해보고 알게 된 거예요
흰 글씨에 무슨 말을 쓸지 고민을 많이 했어요. 사진을 한눈에 느끼게 하는 문구를 제가 지으려니 어려웠어요.
그래서 "음식을 분석해서 문구를 직접 만들어줘"라고 프롬프트에 적었어요. 그랬더니 AI가 알아서 써줬어요.

2쓰는 법 3단계

  1. 챗GPT 앱을 열고 + 버튼을 눌러 음식 사진 한 장을 올려요.
  2. 아래 프롬프트를 복사해서 붙여넣어요.
    [ ] 안은 필요하면 바꾸고, 그대로 둬도 괜찮아요.
  3. 나온 그림을 길게 눌러 저장해요. 마음에 안 들면 "다시 그려줘"라고 해요.

3프롬프트

한글 프롬프트
제공된 이미지를 메인 피사체로 사용해 독창적이고 감성적인 푸드 포스터를 만들어줘.
음식의 형태, 재료, 구성, 카메라 앵글, 조명은 바꾸지 마.

■ 콘셉트
음식을 작은 손그림 캐릭터들이 살아가며 상호작용하는 작은 판타지 세계로 변환하되,
동시에 비주얼 다이어리 + 브랜드 광고 같은 감정적인 반응을 담아줘.
텍스트, 반응, 상호작용 등 모든 요소는 음식을 시각적으로 분석해서 자동으로 생성되어야 한다.

■ 캐릭터 스타일
· [작고 하얀] 스케치 캐릭터
· 단순하지만 표정과 감정 표현이 풍부할 것
· 약간 불완전한 손그림 느낌
· 각 캐릭터는 서로 다른 행동과 감정을 보여줄 것

■ 캐릭터 상호작용
· 캐릭터들은 음식의 실제 요소들과, 시각 분석을 바탕으로 물리적으로 상호작용해야 한다
· 바삭한 질감, 소스, 면, 김, 층, 증기 같은 요소를 놀이공간처럼 활용해줘
· [점프하기, 미끄러지기, 껴안기, 빠지기, 올라가기] 같은 역동적인 행동을 보여줘

■ 드로잉 스타일
· 일반적인 두들보다 약간 더 두꺼운 흰색 손그림 라인
· 음식의 전체 외곽선을 모두 따지 말고, 핵심 엣지와 하이라이트만 선택적으로 따라 그리기
· 움직임선, 충격 표시, 흐름 곡선 추가
· 작은 반짝임, 김, 포인트 표시 같은 최소한의 아이콘만 넣고 전체는 깔끔하게 유지

■ 텍스트 스타일
· [한국어] 손글씨 스타일
· 가독성을 위해 획은 약간 더 두껍게
· 정렬된 타이포가 아니라 자연스럽고 들쭉날쭉한 간격
· 깔끔한 폰트처럼 보이면 안 됨

■ 텍스트 생성 규칙
· 음식의 질감, 재료, 온도감, 분위기를 자동으로 분석해 텍스트를 생성해줘
· 고정된 예시는 사용하지 말고, 모든 문구는 새롭게 만들어줘
· 흔한 표현은 피하고, 진짜 즉흥적으로 떠오른 생각처럼 느껴지게 해줘

■ 텍스트 구조
1. 메인 슬로건 → 짧고, 강렬하고, 감정적인 한 줄 (브랜드 카피처럼)
2. 캐릭터 반응 메모 → 각 캐릭터 주변에 배치
3. 감각 파편 문구 → 맛과 질감을 바탕으로 한 짧고 끊긴 표현
4. 마지막 감정 문장 → 일기처럼 마무리되는 한 줄

■ 레이아웃
· 강한 여백을 유지해줘
· 캐릭터와 텍스트를 음식 위에 자연스럽게 흩뿌리듯 배치
· 대칭은 피하고, 날것 같지만 균형감 있게 구성

■ 무드
[장난스럽고 + 감성적이고 + 약간 시네마틱한] 분위기
디자인된 그래픽이라기보다, 우연히 포착된 순간처럼 느껴져야 한다

■ 마무리
· 원본 음식의 리얼리즘은 유지
· 대비는 살짝만 올리기
· 아날로그 무드를 위해 은은한 그레인을 추가하기

4바꿔도 되는 곳

  • [작고 하얀]

    어두운 사진에 올릴 때 → 작고 검은

    아이 느낌으로 → 작고 노란

  • [점프하기, 미끄러지기, 껴안기, 빠지기, 올라가기]

    차분하게 → 앉아서 보기, 기대기, 손 흔들기

    더 신나게 → 뛰어내리기, 서핑하기, 매달리기

  • [한국어]

    해외 손님이 많으면 → 영어

    글씨 없이 그림만 → 이 줄을 지우고 "글자는 넣지 마세요"로 바꿔요

  • [장난스럽고 + 감성적이고 + 약간 시네마틱한]

    가게 홍보용으로 → 따뜻하고 + 정겹고 + 깔끔한

    일기처럼 → 조용하고 + 잔잔하고 + 서정적인

5어려운 말 풀이

  • 메인 피사체사진에서 주인공이 되는 대상이에요. 여기서는 음식이에요.
  • 두들낙서처럼 쓱쓱 그린 그림이에요. 영어로 doodle 이라고 해요.
  • 슬로건광고에 크게 들어가는 짧은 한 줄 문구예요.
  • 타이포글자를 디자인해서 배치한 거예요. 여기서는 "반듯한 글씨처럼 보이지 말라"는 뜻이에요.
  • 레이아웃화면에 무엇을 어디에 놓을지 짜는 거예요.
  • 대비밝은 곳과 어두운 곳의 차이예요. 올리면 또렷해져요.
  • 그레인필름 사진처럼 아주 작은 알갱이가 보이는 느낌이에요.

6막혔을 때

  • 직접 겪음글씨에 뭐라고 써야 할지 모르겠어요

    제가 제일 오래 고민한 부분이에요. 직접 지으려고 하지 마세요. 프롬프트 안의 "텍스트 생성 규칙"이 그래서 들어가 있어요 — AI가 음식을 보고 알아서 문구를 만들어요. 그 부분을 지우지 말고 그대로 두고 돌리면 돼요.

  • 한글 글씨가 깨져 나와요 (예상)

    AI가 제일 자주 틀리는 부분이에요. "다시 그려줘"를 두세 번 해보세요. 그래도 깨지면 글자 수를 줄여 달라고 하세요. 짧은 말일수록 잘 나와요.

  • 캐릭터가 너무 많아서 복잡해요 (예상)

    "캐릭터는 네 명까지만 넣어주세요"라고 숫자를 정해 주세요. 숫자를 말하면 잘 지켜져요.

  • 음식이 캐릭터에 가려요 (예상)

    "캐릭터는 음식의 가장자리에만 두고, 음식 위를 덮지 않게 해주세요"라고 덧붙여 주세요.

  • 음식이 원본과 달라졌어요 (예상)

    맨 앞 문장을 한 번 더 강조해 주세요. "음식 사진은 하나도 바꾸지 말고, 그림과 글씨만 위에 얹어주세요"라고요.

잠깐만요. 본인이나 동의받은 사람의 사진으로 만드세요. 다른 사람 사진을 허락 없이 쓰면 안 돼요.
